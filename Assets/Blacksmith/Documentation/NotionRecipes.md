# Notion 크래프팅 레시피 반영

출처: [데이터 베이스 / 크래프팅 레시피](https://app.notion.com/p/8879c4aa4b9c831884ad815a79adf309)

Notion은 읽기만 했습니다. 해당 문서에는 직접 자식 페이지가 없었으며, 다른 항목인 전체 아이템 & 장비 및 합금 효과 링크는 열지 않았습니다.

## 반영 범위

- 총 189개 제작 경로를 저장하고 129개를 활성화했습니다. 동일 결과물의 대체 제작법 및 부산물의 혼합 비율은 별도 경로로 계산합니다.
- 나무, 돌, 철, 가죽, 접착제, 흡혈 강철, 강철과 부산물 재활용을 적용했습니다.
- 가공 횟수 범위, 다중 결과 수량, 재료 비율, 모루 5회 패턴, 담금질을 반영했습니다.
- 섬유 8개, 나무 토막 2개, 판석 조각 2개, 작은 돌 조각 3개, 돌/철/흡혈/강철 화살 25개를 배수 제작에도 적용합니다.
- 금속 부산물 3개는 단일 재료 3개, 1+2, 2+1 조합을 모두 지원합니다.
- 가죽 2개+실 2개처럼 결과가 겹치는 조합은 결과 선택창에서 모자 2개 또는 조끼 1개를 선택합니다.
- 머리/몸통/하의/신발 슬롯을 분리하여 제작한 방어구를 함께 장착할 수 있습니다.
- 히든 날카로운 나뭇가지는 제작 가능하며 기존 발견 조건에 따라 레시피 목록에 나타납니다.

## 보류 및 미정 항목

- 화염·바람 계열 58경로와 흑요석 계열 2경로는 데이터에 보존하고 제작은 비활성화했습니다. 문서의 테마 시스템 삭제 표기와 미기재 가공 횟수를 이유로 한 보수적 해석입니다.
- 화염·바람 숫돌 횟수는 문서의 ‘철과 동일’이라는 공통 설명을 적용해 저장했지만, 제작을 활성화하지 않았습니다. 해당 계열 화살은 개별 기재된 10개를 유지했습니다.
- 흑요석 화살촉의 가공 횟수는 0으로 미정 상태를 표시하고, 제작을 차단했습니다.
- ‘강철 흉’은 대응 부위에 맞추어 표시명을 ‘강철 흉갑’으로 정리했습니다. Notion 원문은 바꾸지 않았습니다.
- 장비 스탯·합금 효과 문서를 열지 않았으므로 수치를 창작하지 않았습니다. 신규 카탈로그 공격력/방어력/가격은 미설정 0, 공격속도는 기본 1입니다. 전용 아이콘은 기존 범주별 스프라이트를 재사용합니다.
- 숙련도 5회 성공 시 레벨 2, 장인급 미해금 등 기존 테스트 설정은 유지합니다.

## 사용법

`Assets/Blacksmith/Scenes/BlacksmithShop.unity`를 열고 Play 합니다.

1. 홈의 **테스트 재료 받기**를 누르면 활성 레시피에 필요한 채집 재료와 연료를 보관함에 종류별 최대 30개까지 보충합니다. 기존 저장을 초기화하지 않습니다.
2. 철 원석 → 용광로 → 달궈진 철 → 모루 상2/하2/중앙1 → 달궈진 긴 철 칼날 → 담금질 → 긴 철 칼날.
3. 나무 원목 → 톱5~6회 → 나무 판자 → 톱3~4회 → 나무 토막 2개 → 칼6~7회 → 나무 자루.
4. 이끼 슬라임의 점액 2개 → 용광로 → 강력한 접착제.
5. 긴 철 칼날 + 나무 자루 + 강력한 접착제 → 작업대 → 철 검.
6. Tab은 발견한 레시피를 표시하며, 가공 횟수와 결과 수량도 표시합니다. 성공 제작 5회 후 자동 제작이 열립니다.

## 파일과 갱신

- `Assets/Blacksmith/Data/NotionRecipes.json`: 원문을 구조화한 스냅샷. 외부 Notion과 실시간 연결하지 않습니다.
- `Assets/Blacksmith/Data/TestCatalog.asset`: 기존 GUID를 유지한 실제 실행 카탈로그. 이름은 저장/씬 참조 호환을 위해 유지합니다.
- `Blacksmith/Import Notion recipe snapshot`: JSON을 기존 카탈로그에 적용하고 검증합니다. 해당 메뉴는 레시피 목록 및 스냅샷에 포함된 아이템 정의를 교체합니다.
- `Blacksmith/Build playable scene and verify`: 스냅샷 적용을 포함해 씬/프리팹을 다시 생성합니다. 수정 중인 씬은 먼저 저장하세요.
- 기존 아이템 ID와 저장 데이터는 유지합니다. 임시 레시피 숙련도는 새로운 Notion 레시피에 자동 승계하지 않습니다.
- 전체 경로, 재료, 횟수, 수량, 활성 상태는 `레시피_반영_목록.csv`에서 확인할 수 있습니다.

## 검증

Unity 6000.3.11f1에서 기존 도메인 검사 26개와 실제 레시피 검사 3,182개 통과. 각 활성 레시피의 범위 양 끝값, 1회/2회 배수 제작, 결과 수량, 재료 보존, 연료 소모, 잘못된 비율/횟수, 비활성 차단, 중복 조합의 선택 요구와 자동 제작 수량을 검사합니다.
