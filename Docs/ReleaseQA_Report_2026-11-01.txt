저장/씬 이동 최초 지연의 분리된 정밀 계측은 미완료. 평균FPS만으로 출시 성능을 단정하지 않는다.

8. 남은 문제·분류·결정
A-04 [재현/미수정] 튜토리얼 석상에서 동화율이 이미0인 준비 상태: 제물 Commit은0이라 거절하고, 튜토리얼은 제물 완료 전 닫기를 거절하여 막힘.
근거: zero-boundary.json, zero-reproduction-run.json. 후자의 passed는 '문제 재현 성공'이지 기능 통과가 아니다.
정상 순차 경로는 양수 동화율로 석상 사용하여 통과했다. 처음 잘못0이라고 기록한43상태/제물1개 부족은 자동화 오류로 정정했고 게임 버그 근거로 쓰지 않았다.
권장안(사용자 답변 대기): 이미0임을 안내하고 재료 소비 없이 닫으면 다음 단계. 완료 조건을 새로 정하는 판단이므로 승인 전 적용하지 않음.

B [미검증] 실제 OS Alt-Tab/최소화/복귀·키 변경 후 네이티브 입력. 승인된 computer-use의 node_repl 실행 도구가 이 세션에 없어 사용 못함. Win32 입력 우회는 만들지 않았다.
B [미검증] 전체 경사/벽/플랫폼 조합, 모든 무기·몬스터 경계, 실제 상점 전체 UI·설정 적용/취소/키 변경, 수시간 안정성.
B [미검증] 진짜 디스크 고갈/정전/강제 프로세스 종료 시 각 제작·거래 중간 복구, 다른 Windows 계정/PC, 오프라인 새 환경과 추가 설치 경로 변형. 잠금·권한 실패는 별도 재현했으며 이를 전부 대체하지 않음.
엔딩 기한 전후의 모든 조합은 현재 버전에서 별도 실행하지 않았다. 정상 Scene6-1과 준비된 두 엔딩 조건은 실행했다. Scene6-2는 branch6.json/branch6-reload.json의 실제 결과를 별도 기록한다.
C [범위 밖] UI 디자인/배치/색상과 사운드, 경제/난이도/엔딩 규칙 변경, 콘텐츠 추가. 수정하지 않음.
라이선스: 로컬 Pretendard OFL1.1과 Cainos MIT 표기, PixelUI Documentation 확인. 구매 권리/모든 에셋 배포 조건/스토어 요구사항은 미확인. 법적 적합성 보장 안 함. 제작자 이름을 지어내지 않음.

9. 자동화 실패와 게임 실패 구분
잘못된 석상 대상, 부족한 제물 수량, 포커스/드롭 이름, 초기 몬스터 스폰 대기/작성된 체력300을 기본130으로 오인한 검사는 픽스처 오류로 보관했다. 관련 CSV/난이도 값을 바꾸지 않았다.
초기 Windows sandbox 실행의 저장 경로 거절은 테스트 환경 문제였다. 자동 승인 검토가 무보호 상승 실행을 거절했다. 이후 기대 QA 절대 저장 경로 가드를 실행 시작 전 추가하고 QA working directory에서 실행하여 해결했다. 원본 저장은 쓰지 않았다.
