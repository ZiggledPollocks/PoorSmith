변경
- PixelUI Wood 에셋의 버튼 4상태·9분할 패널·슬롯·입력란·체크박스·슬라이더·스크롤바를 기존 컨트롤에 연결했다. 이벤트·아이템·경제·저장 규칙은 바꾸지 않았다.
- 타이틀 버튼(플레이하기·이어하기·저장 목록·설정·종료)에도 적용했다. 설정이 TitleMainMenu 뒤에 가려지는 기존 렌더 순서를 OpenSettings의 SetAsLastSibling으로 보정했다.
- 창작 배경은 작업대 crafting_1, 도구걸이 crafting_2, 담금질 crafting_3, 모루 crafting_4, 용광로 crafting_5에 연결했다. 작업대→도구걸이→모루→담금질→용광로 enum 순서는 유지했다.
- 배경에 이미 그려진 도구 위에 투명 클릭 영역을 연결했다. 칼은 중앙, 톱은 왼쪽, 망치는 오른쪽, 대패는 왼쪽 아래, 숫돌은 오른쪽 아래에 맞췄다. 이름표 사이 간격, 화면 이동 화살표, 연료 버튼·안내문 겹침을 조정했다.
- 새 PNG를 Point 필터·무압축·밉맵 없음으로 가져온다. 기존 GUID·분할 정보는 유지했다.
- 실제 폴더 source/아이콘-20260930T051008Z-1-001/기타의 바람의_결정.png, 워프석_OFF.png와 워프석_ON.aseprite를 참조한다. 활성화 Aseprite의 기존 클립16프레임·키 시간을 사용한다.
- 바람 결정은 현재 구현된 워프 해금 상태와 획득 안내의 그림을 연결한다. 새 재료나 인벤토리 규칙은 만들지 않는다.
- 워프석은 시각 전용 자식으로 기존 표시 높이를 유지하며 실제 지면에 받침대를 맞춘다. 원래 트리거·stableId·저장 위치는 보존한다.

기존 버튼과 상호작용을 그대로 사용한다. 공통 참조는 Assets/JinHo/Resources/UI/GameArtSkin.asset에서 조정한다. 지도 구조·아이템 아이콘·초상화·어울리지 않는 삽화는 유지한다.

검증
- 독립 Unity6000.3.11f1 복사본의 C# 컴파일 통과.
- TitleScene→이어하기(필드 재개 시 마을 귀환 포함)→SampleScene 상자·상점·전당포·납품·지도·결정 안내→대장간 다섯 작업 화면→FieldMapStructureTest 실제 워프석 위치·장비창을 검사했다.
- 최종155개 자동 검증 통과. 이벤트 객체 보존, 버튼 상태 이미지, 실제 레이캐스트, 재료 선택, 도구5종의 실제 선택, 용광로 연료 화면, 레시피 진입, OFF/ON·애니메이션 진행, 지면 높이를 확인했다.
- 화면에서 설정 가림, 이름표 겹침, 결정 그림·안내문 겹침, 워프석 부유를 확인하고 수정했다. 최종1920×1080 Game View 캡처를 검토했다.
- 조작은 합성 EventSystem 입력과 준비된 격리 상태를 사용했다. 실제 OS 마우스·키보드 조작 및 모든 레시피 미니게임 전체 과정, 모든 튜토리얼·엔딩·해상도와 플레이어 빌드는 미검증이다.
- 실제 사용자 저장·설정 파일 해시 동일. 검증용 Pipeline·테스트 코드는 원본에 반영하지 않았다. 씬·기존 프리팹은 재저장하지 않았다.
