1280×720·1440×900 캡처는 같은 폴더에서 파일명 해상도로 확인한다. 재설계 전에 모든 조건의 캡처를 확보하지 못했으므로 해당 변경 전 칸은 미확보로 표시했다. 스크롤 중 부분 행은 연속 스크롤을 유지하며, 초기 목록의 온전한 행과 패널 내 뷰포트를 확인했다.

확인 유형: UI 데이터 준비/코드 프로브, EventSystem 합성 입력, Play Mode, 렌더된 Game View 검토. 실제 OS 마우스·키보드와 player build 검증은 이번 작업에서 수행하지 않았다. 테스트용 준비 상태를 신규 사용자 테스트나 전체 게임 통과로 취급하지 않는다.
